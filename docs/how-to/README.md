# How-to guides

A how-to guide is a **recipe for one task**. It assumes you already know the app's content model —
what a song is, what a setlist is, how roles work — and that you are looking for the exact steps
and settings to accomplish something.

If you are new here, start with the [tutorials](../tutorials/README.md). If you want to know *why*
something works this way, read the [explanation section](../explanation/README.md). If you need to
know what a file, route or variable accepts, use the [reference](../reference/README.md).
