# 0011 — Two Navidrome instances: originals and per-voice

- **Status:** Accepted; voice matching is text-based
- **Date:** 2026-09-24
- **Relevant code:** `src/lib/navidrome.ts`, `src/lib/navidrome-voices.ts`, song `meta.voiceSongs`

## Context

The app plays backing tracks. The requirement split in two:

1. The **original** version of a song — the canonical recording — following the canonical language.
2. **Voice-specific mixes** — the same song cut per vocal range (e.g. male/female), generated by a
   separate DJ workflow, to serve on setlists.

A single Navidrome instance conflates them, and the voice track naming (`-art`, `-bass`, `-tenor`,
`-lead-vocal`) differs from song titles, so a single find-by-title query kept failing for voices.

## Decision

- Run **two independent Navidrome servers**, configured by separate env vars:
  - `NAVIDROME_URL` / `NAVIDROME_USER` / `NAVIDROME_PASSWORD` — original audio, per-language.
  - `SONGS_NAVIDROME_URL` / `SONGS_NAVIDROME_USER` / `SONGS_NAVIDROME_PASSWORD` and
    `VOICES_NAVIDROME_URL` / `VOICES_NAVIDROME_USER` / `VOICES_NAVIDROME_PASSWORD` — separate
    servers for songs audio and voice mixes (two more instances; the dance/music room's workflow).
- Matching is by title similarity plus manual pinning: the admin links a song to a Navidrome
  track once, and the links are stored in `meta.spotify`/`meta.voiceSongs`/setlist
  `voiceShares`.
- The playlists ("voice playlists") are *generated* per setlist by hitting the voice server and
  are stored back as `voiceShares` on the setlist, per share/owner — so they outlive the request.

## Consequences

**Positive**

- Originals and mixes never collide, and the voice server can be owned by a different team or
  machine than the song server.
- Linked tracks are explicit data, not re-guessed on every request; the link survives restarts.

**Negative**

- Text-title matching remains the fallback for voice track lookup, and it is fragile — a
  mistitled voice file does not get found.
- Three Navidrome endpoints is a lot of configuration surface; forgetting the voice server silently
  disables voice playlists.
- Generated `voiceShares` are written into content and must be re-generated if the voice server
  changes; they are a snapshot, not a live query.

**Carried forward**

- The removed [music importer](./0014-the-music-importer-was-removed.md) was the previous answer to
  "connect the files to the app"; Navidrome links supersede it for audio, and it is gone.
